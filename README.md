### Assign 6.5: Location Information
This app gets a user's location permission, displays a google map centered at that location with a marker and the address information, and allows the user to place custom markers by tapping the map. 

In order to run this app, you must update the file "app/src/main/res/values/google_maps_api.xml" with your API key.
